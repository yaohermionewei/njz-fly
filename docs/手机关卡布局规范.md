# 手机关卡布局规范

目标是保留原关卡体验，只处理1.5倍实体带来的局部拥挤。完整逐项记录见[手机关卡逐项排查与恢复](手机关卡逐项排查与恢复.md)。旧的39套独立重排已撤出运行时，不能继续以删管、删分支、统一中线来适配。

## 原设计是基准

`readSegmentDesign` 在构建原片段时记录每条奖励路线的控制点、角色与间距，原版输出不变。`buildOriginalPhoneLayout` 保留原障碍和猪的数量、左右顺序、朝向、斜角、支撑关系、巡逻速度/范围/相位、路线分支及随机变体，再逐段调整冲突的位置。横管使用原作者长度×375/410×1.5，不能缩短它来塞空间。天地管保留锚点，缩短长管也不能把它变成悬空管。

开头保留原来的平飞、爬升、停留和下降。休息段恢复原160间距对应的稀疏节奏；普通连续路线最小采样87，较疏的110/160/200等原设计继续按比例保持较疏。分叉只在公共出口合并重叠的指路点，两条分支都保留。奖励图案不能被特殊物品覆盖或随意抽点；兔头和铃铛在720高世界内采用有记录的紧凑完整点阵，4×6方阵、实心爱心和NJZ的角色与结构保留。

## 空间和玩法同时检查

拾取物动画轮廓之间至少18，到管口/积雪至少24，水管之间至少36。宽主通道优先216；原有动作通道和分支不能一律改成同宽大通道，应按完整120高角色加余量检查：通常136，走廊外侧132，大S为192。具体位置和例外在逐项记录中说明；不缩小角色或碰撞框来通过。

2026-10-31 手机体验反馈后，门缝改为按完整角色扫过的路线计算上下管端，保留真实转向压力。双门、阶梯、回旋、波浪隧道、三层楼出口、穿门打猪、下台阶打猪与副歌冲刺约为200–270开口；漏斗400→290→220逐级收紧。计算在镜像完成后进行，因为积雪始终位于屏幕朝上表面。门阶梯每级100保持，进出端平接，避免尾端为延长斜线而缩成短桩。

禁止极短管身：天地锚定管在画面内至少露出100，悬空管长至少138。走廊中间立管上沿342保持，向下延长到158并接实下方横管，形成明确T形。只有通过 `isPipeJunction` 的完整接合可例外于普通36间隔；不能把任意重叠标成连接以通过检查。两实体的碰撞并集完整保留，连接端在横管后方绘制，外侧绕行继续存在。

三层楼、走廊内外路线、射击接近窗口和冒险奖励是不同玩法，不能统一成安全中线。双门、回旋、波浪、编织、大S、冲刺必须保留原有动作要求：回归测试会检查障碍仍会挡住全程不换高度的中线，而不是只证明应援棒画成了曲线。

验证包含可见间距、完整角色通行包络、不射击可穿越、收集后可继续离开，以及导演从真实入口串接。跨段检查按原路线的出入口控制点连接，不因特殊物品替换普通棒而改变；不把一段内部的射击接近窗口、散块前的短引导强行延长穿过其后的障碍，自由飞行部分由连续可达求解器检查。爱心、太阳花和头像预留各自完整动画范围，不能覆盖已有特殊物品，放置后再检查。

## 比例与节奏

完整展示720高世界，背景比例和固定镜头不缩放、不跟随。手机实体1.5倍；横向物理位置、片段宽度、实际移动量同步乘1.5。音乐距离仍为375单位/秒，手机实际横移562.5；分数、BGM、小节时长和结尾不变。每个物理小步不超过1/60秒，手机进后台暂停。Pad和电脑继续原构建与编排。

所有横管、竖管和斜管，两端均绘制完整管口、卷边、凹槽和螺栓；包括正向与镜像，积雪只落在朝上表面。封口修复使用共享绘制器、全端生效；默认布局位置/数量保持原基准。图案、角色和背景沿用既有美术。
